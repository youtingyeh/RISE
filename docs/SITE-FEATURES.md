# 網站功能開放設定

## 啟用

在既有帳號系統上，於 Supabase SQL Editor 完整執行 `backend/site-features.sql`。不需要重新部署 Edge Function，也不需要重跑 setup.sql。本檔獨立於 security-hardening.sql，但不取代前次安全修補。

登入已驗證的管理員帳號 → 管理員專區 → **功能開放設定**。每個開關按下即儲存。初次安裝全部維持開放，避免中斷現有使用；重跑 SQL 不會重設已選設定。

「套用精簡模式」會確認後只保留科學探索、影音探索、學生提問及重要日程，其餘可切換區域關閉。首頁、關於計畫、核心團隊、登入／註冊、會員中心與管理工具不會被關閉。三學科檔案和所有教材均保留。

## 生效範圍

- 關閉區域的導覽、頁內連結和標示的功能卡片會隱藏；直接網址顯示「尚未開放」。
- 教師、助教、學生、訪客皆遵守開放設定。只有後端確認為已驗證管理員可預覽關閉區域、準備資料。
- 新開啟頁面讀取最新設定。已開啟分頁在切回／視窗取得焦點，或可見狀態下每 60 秒更新一次，不使用永久的本機設定快取。
- 網路讀取失敗時，非管理核心區域暫時不顯示功能；返回首頁、登入與會員中心仍可使用。SQL 尚未安裝時維持舊版開放狀態，管理員設定區明確提示需安裝。
- 儲存衝突不覆蓋另一管理員的變更；重新讀取後再操作。後端記錄執行者、變更內容、版本及時間。

## 安全界線

這是**網站發布／展示開關**，不是 API 停權開關或機密資料保護機制。關閉不撤銷已取得的下載連結，也不改變既有 RPC／Storage 的讀寫授權。直接呼叫 API 仍由原有 RLS 和角色／課程權限決定。若有內容必須真正撤回存取，請使用該內容的下架功能及相應的後端權限管理，不要只依靠這個開關。

設定及操作日誌放在 `rise_private`，啟用 RLS 並禁止直接讀寫。公開唯讀 RPC 只回傳功能開關、版本、更新時間與當前呼叫者是否為管理員；寫入 RPC 驗證管理員、信箱驗證、允許的功能名稱、布林格式及版本。

## 檔案

- `site-features.js`／`.css`：全站入口與頁面開放狀態。
- `admin-features.js`：管理員開關與精簡模式。
- `admin-console.js`／`role-navigation.js`：設定入口。
- `backend/site-features.sql`：持久設定、管理員更新與操作紀錄。
- `tests/security/test-features-db.mjs`／`test-features-ui.mjs`：權限、衝突、顯示、失敗與預覽測試。
