# 2026-10-13 視覺更新：朱批筆記本

基準：GitHub main `846c986`。本次只調整外觀與首頁主視覺的示例內容，沒有修改資料庫、權限、帳號流程或任何 SQL。

## 設計方向

- **白紙＋墨藍文字**：內文與標題改用墨藍色（#1d2b46），段落顏色加深，閱讀更清楚。
- **方格紙**：首頁主視覺、各頁標題區與帳號頁標題區使用淡方格底紋，呼應數理演算的筆記本。
- **朱筆**：朱紅色（#c63a2c）代表助教的批改筆，用在目前所在頁的選單底線、文字連結底線、鍵盤焦點框與首頁批改示例。
- **學科色**：數學鈷藍、物理青綠、化學赭色，三科都保留。
- **字型**：仍只用系統字型，不向外部請求字型或圖片。首頁批改筆跡使用楷體（Windows 標楷體、macOS 楷體；沒有楷體的裝置自動改用一般字型）。
- 標題上方的英文眉標（例如 ABOUT RISE）不再顯示；學科卡的英文名改為斜體小字。

## 首頁

- 右側卡片改為「提問示例」：一個數列與級數的學生提問，加上助教的三種回饋（思路分析、改進建議、延伸提問），示範計畫書的批閱三要素。卡片標示為示例，不是正式教材。
- 「答案之外，留下思考的足跡」的四個步驟改畫成一條數線；手機上改成直式時間線。
- 雙軌介紹改為兩欄並排，不再是兩張卡片。

## 修改檔案

- `theme-rise.css`：全站主題重寫（色彩、頁首、標題區、按鈕、卡片、表單、頁尾、首頁元件、日程與個資頁的配色對應）。
- `script.js`：首頁主視覺示例、雙軌標籤、學科卡英文名（移除 01／02 編號）、帳號列底色改用主題變數。
- `join.html`：標題包成 `join-heading`，讓標題區可延伸成整幅方格紙。
- 所有 HTML：`theme-rise.css` 與 `script.js` 的快取版本改為 `design-20261013-1`。
