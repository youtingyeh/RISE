## 不採用或暫緩

- **1-2 移除化學：不採用。** 使用者明確要求完整保留數學、物理、化學；三科入口、頁面、資料關聯及 sitemap 都保留。
- 不將計畫書中關於教育衰退、PISA/TIMSS 的論述直接改寫成已查證的客觀結論。本次沒有增加這些宣稱。
- 不製作新教材、示範習作或虛構公開試看單元。教材仍由團隊維護。
- 不自行新增顧問角色、公開助教姓名、同儕互評權限或學生分享機制；這些會改變現行資料可見範圍，應另行設計與測試。
- 助教排班、人員真實在線狀態、評價月報、抽查派工及服務時數證明屬獨立功能，這次不把排班等同實際出勤，也不生成未經驗證的證明。
- 招募頁所列培訓、獎勵、續任及學校補助均區分為計畫規劃；人名、名額、梯次、辦法與日期未提供者不編造。
- 不用部署時的靜態 features.json 覆蓋管理員的即時開關，避免陳舊設定重新開放已關閉功能。開關仍是介面開放控制；資料存取由既有 RLS/RPC 負責。
- GitHub Pages 專案位於 `/RISE/`，搜尋引擎的 robots.txt 規則需放在網域根目錄。本次不在專案子目錄放一份看似生效的封鎖規則；使用頁面 noindex 與 sitemap，不把它們當作存取權限。
- 未重製完整頁首、教材公式系統、AI 習作分析、活動申請或年度合輯；也不宣稱已完成整份建議檔。

## 部署與維護

- 本次**沒有 SQL Migration，也不需要重新部署 Edge Function**。
- GitHub Pages 部署後，重新整理即可載入；改動的腳本引用版本為 `public-review-20261012-1`。
- 網站開放設定沿用既有 `backend/site-features.sql`，本次不要求重跑。
- 未修改 Supabase 正式資料、使用者角色、信件設定或 auth-config.js。
- 未來調整頁面標題或介紹後，執行 `node tools/generate-site-metadata.mjs` 更新靜態 metadata 與 sitemap，再執行 `npm run check`、`npm test`。
- 分享平台可能快取舊預覽圖；更新 metadata 不代表所有平台的快取立即更新。
- 公開頁 sitemap 不包含登入或管理頁。功能開關即時設定不會改寫靜態 sitemap；如要搜尋引擎移除某頁，需另行設定該頁 noindex 並部署。
- 可由本次提交的父提交回復程式；不涉及資料庫回復。
