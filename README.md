# RISE 計畫導向升級草稿

依據：使用者提供《數思新生計畫書》2025-11-05 修訂版，共 13 頁。原始 PDF 不隨此修改公開。

## 內容界線

- 使用者已確定的品牌 RISE／Reasoning and Inquiry for Science Education／國立臺灣大學數思新生計畫保留。計畫書封面英文為 The Renaissance of Reason；未擅自替换既定品牌。
- 主要受眾：具數理興趣與傾向的高中生；提問營與競賽規劃另涵蓋大專生（第 5、7 頁）。
- 初期以數學為主，物理接續；化學為使用者後續擴充需求，非本版計畫已有獨立課程（第 4–6、12 頁）。
- 營運中心在封面為擬設。團隊顯示規劃職責，不暗示已有人員到任。
- 不將 PISA/TIMSS 趨勢、課綱因果論述轉寫為網站上的已查證事實。
- 不發布內部年度 KPI、捐助規劃、未確認的認證或招生承諾；計畫目標不當成已達成成果。

## 草稿功能的實際限制

- 保存是使用者按鈕觸發的瀏覽器 localStorage，每份最多保留 20 版。
- 支援載入舊版、未保存離頁提示、匯出目前版本為 TXT、清除此份紀錄。
- 本機保存不等於跨裝置同步；不代表正式作業提交、助教已批閱、能力達標或完成認證。
- 共用電腦提醒、儲存失敗提示與匯出備援已提供。沒有要求輸入姓名、學校或身分證等個人資料。
- 沒有正式課程題目與影片時，仍呈現待提供。未虛構題目、影片時長、學者對談或活動日期。

## 正式平台的後續必要工作

1. 課程團隊提供已審核單元：先備概念、能力目標、影片、每單元 3–5 題及回饋依據。
2. 帳號與分角色授權、受保護的作業儲存、提交版本及助教分派，需另建後端。不得將學生作業放入公開 GitHub。
3. 由授權教師維護批閱規準；回饋須包含三要素，並支援學生修訂及教師抽查。
4. 營隊、競賽、學者對談、問題年鑑需正式公告與發布同意流程；目前僅說明機制。
5. 學習完成率及錯誤類型分析須基於實際活動資料，不能用看完影片取代能力評估。AI 問題顧問與分析不在此靜態草稿中假裝啟用。
