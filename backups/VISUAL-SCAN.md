## 既有問題與檢查限制

1. backend/admin-console.sql 的 update_member、delete_member 使用單一 $ 而非 $$ 作為函式界定符，安裝檔會語法錯誤。正式資料庫可能已手動修正，不能由檔案推定線上狀態。
2. 該刪除函式直接刪 storage.objects 記錄，不能作為可靠的實體檔案清理流程；需獨立改為 Storage API 工作流程並驗證。
3. discussions.js 宣稱所有登入成員可閱讀及連續回覆，但 backend/discussions.sql 仍限制單人單題一次回答及私人閱讀權限。未在美化過程中公開歷史私人回答；需獨立確認遷移方式。
4. 本次未使用任何會員憑證，未實際提交提問、作業、刪除帳號、寄信或變更角色。靜態檢查不等同正式後端操作驗收。
5. 沒有把企劃書原檔或內部個資放入公開網站。
