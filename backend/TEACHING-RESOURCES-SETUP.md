# 教學資源管理啟用

1. 既有專案於 Supabase SQL Editor 新增 snippet，執行 teaching-resources.sql。不要重跑原 setup.sql。
2. 等待 GitHub Pages 更新後，在 resources.html 按 Ctrl+Shift+R。
3. 用已核准教師或管理員登入。按「新增資源」，填寫標題、學科、類型、簡介、文章內容，附教材檔案或 YouTube 網址。
4. 儲存草稿或發布。以學生／未登入視窗確認公開列表與下載權限。發布後可透過編輯中的「儲存草稿／下架」移出公開列表。

## 權限
- 管理員管理全部；教師建立及管理自己的資源；助教／學生無編輯權。
- 草稿只供作者（仍具有教師資格）與管理員查看。
- 公開文章可不登入閱讀；教材及上傳影片需已驗證登入帳號下載／播放。YouTube 公開影片本身不能靠本網站登入限制阻止外部觀看。
- 資料庫禁止客戶端直接寫表，所有儲存經驗證角色、作者、版本、檔案歸屬的 RPC。
- 文章是純文字及段落，不接受 HTML；未提供富文字工具列。

## 儲存與限制
- 教材、圖片與影片使用獨立 Supabase 私有 bucket rise-teaching-files，並非先前資格證明用的 Google Drive。
- 每個資源最多5檔、單檔50 MiB；PDF/DOCX/PPTX/JPG/PNG/WebP/MP4/WebM。實際仍受 Supabase 專案容量／檔案限制影響。
- 標準上傳不支援斷點续傳；網路中斷需重新選擇尚未成功的檔案。長影片建議貼 YouTube 網址。
- 保存標題／內容與附件關聯為同一交易。上傳與資料库交易無法合併；模糊網路失敗或替換附件的舊檔保留，以免刪掉實際已提交檔案。尚無自動清理孤立檔案排程。
- 短期下載／影片網址有效5分鐘；下架後已簽發網址可能持續有效至到期。長影片如到期後無法拖曳，需再按播放取得新網址。
- 本版提供登入者資源開啟時間紀錄 rise_resource_visits，尚不記錄影片觀看秒數或完成率，亦未整合會員中心紀錄列表。
- 前台刪除帳號會清除本人上傳資源檔案及本人建立的文章／教材；教師刪帳前如需保留課程，請管理員另行整理移交。後台直接刪 Auth 使用者不自動清理 Storage。
- 本次不產生示範文章，既有 resources.html 靜態範例改為資料庫已發布內容列表。

## 驗收
教師甲新增草稿並上傳附件 → 教師乙／學生／未登入者不可讀草稿 → 甲發布 → 公開文字可讀、登入者可下載 → 乙不能編輯甲的資源 → 管理員可修改／下架 → 舊版本保存遭拒避免覆蓋 → 撤銷教師身分後不能再保存。
