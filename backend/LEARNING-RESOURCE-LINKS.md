# 科學探索與學習路徑的教材來源

教學資源為統一編輯入口，但分科學探索區與學習路徑區。教師逐份或批次指定 destination，學生頁面只顯示所屬區域的已發布內容，不再將同一份教材自動鏡像到兩頁。

科學探索以「探索主題」組織，學習路徑以「學習單元」組織；先呈現主題／單元卡片，展開才顯示其中的文章、影片、教材。依設定順序排列，避免整批上傳洗版。

請參閱 RESOURCE-PLACEMENT-SETUP.md 並在 teaching-resources.sql 之後安裝 resource-placement.sql。舊資料保留於科學探索／待整理教材，可批次重新分類。發布、下架、移區後，學生重新載入或按重新整理即可看到變動。

資源使用 resources.html?id=UUID 直接開啟，登入後返回同一教材。未登入觀看／下載限制及教師／管理員編輯權限保持原設定。
