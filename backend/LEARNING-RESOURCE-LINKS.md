# 科學探索、學習路徑與教學資源

- 科學探索 science.html：公開的學科／主題入口，按數學、物理、化學、跨學科找教材。各學科頁亦讀取同一教材庫。
- 學習路徑 learning.html：保留登入要求，以「閱讀文章→影片學習→教材練習」提供使用方式與篩選。這是學習方法建議，不是已排定的課程、先修或教師指定單元順序。
- 教學資源 resources.html：唯一內容來源與編輯入口；保留教師管理本人／管理員管理全部的權限。

## 發布後在哪裡顯示

教師在教學資源選擇學科與類型並發布後，科學探索、對應學科頁、學習路徑及教學資源庫皆從 rise_teaching_resources 讀取。未發布草稿不出現；下架後下次載入或按重新整理就移除。已開啟的頁面不會即時推播更新。

每頁12筆、最近更新優先，可依學科與文章／影片／教材篩選；跨學科有獨立分類。點擊卡片以 resources.html?id=UUID 直接開啟該份內容；登入後返回同一教材。已下架或無權讀取會提示。

無須執行新 SQL，沿用 teaching-resources.sql。文章公開，影片／附件登入規則保持不變。影音探索目前仍為既有影片目錄，未在這次改成教材庫的鏡像。

所有頁面導覽統一以「首頁→關於計畫→核心團隊」開頭。
