# 教材發布區域與主題／單元排版

## 啟用

在已安裝 teaching-resources.sql 的 Supabase SQL Editor 新增 snippet，執行 **resource-placement.sql** 全文。可重複執行。不要只重跑 teaching-resources.sql，會覆蓋新的儲存函式；若新專案先跑 teaching-resources.sql，再跑 resource-placement.sql。

## 教師操作

1. 到教學資源，選「科學探索區」或「學習路徑區」。
2. 新增或編輯教材，選發布區域，填寫主題／單元名稱、學科及類型。相同教師、區域、學科、單元名稱的內容收在同一張卡片。
3. 儲存草稿或發布。草稿不顯示在學生頁面。
4. 整理既有內容：切換「管理草稿與已發布內容」，勾選教材（可跨頁，最多100份），按「整理所選教材」。
5. 選目的區域、填同一單元名稱，用上移／下移排列教材，按「套用歸類與順序」。操作保持原本的發布／草稿狀態，不會自動發布草稿。

## 學生呈現

- 科學探索只顯示 destination=science 的已發布主題。
- 學習路徑只顯示 destination=learning 的已發布單元，保留登入要求。
- 先显示主題／單元卡片，展開才有內部教材連結。每頁12張單元卡，內部內容亦每頁12份。
- 排序為設定數字由小到大，相同數字依首次建立時間穩定排序，不因新增、更新而一再置頂。單元卡排序取組內最小 group_order；調整整個單元排序請選取其全部教材一起套用。
- 不同教師、不同學科的同名單元會分開，避免誤將不同課程混合。
- 同一資源目前只屬於一個發布區域，不會同時顯示在兩邊；可透過編輯或批次整理移區。
- 舊資料的預設為科學探索／待整理教材，不刪除既有文章或附件。可批次搬到學習路徑或正式主題。
- 只重新歸類資源紀錄，不複製或搬動實體附件，不影響原 resources.html?id=UUID 連結。

## 權限與測試
教師只能整理本人資源，管理員可整理全部。批次整理逐筆驗證作者和版本後，以同一交易更新；任何一份已被他人更新都會拒絕整批，避免部分覆蓋。

本機測試涵蓋20份教材只形成一個單元、跨區隔離、草稿排除、分頁排序、越權拒絕、版本衝突與批次更新原子性。可於 tests/placement 安裝依賴後 npm test。
